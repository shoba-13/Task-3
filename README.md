## 📌 About the Project

The **Banking System** is a beginner-friendly C programming project developed as part of the CodeAlpha C Programming Internship.

This application allows users to perform basic banking operations such as creating an account, depositing money, withdrawing money, and checking their account balance.

The project uses **Structures, Functions, and File Handling** to manage and store customer account information.

## ✨ Features

- 🆕 Create a New Bank Account
- 💰 Deposit Money
- 💸 Withdraw Money
- 🏦 Check Account Balance
- 📁 Store Account Details Using File Handling
- 🔄 Menu-Driven User Interface
- 🚪 Exit the Application

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| C Language | Programming |
| Structures | Store Account Details |
| Functions | Organize Operations |
| File Handling | Save Account Information |
| Loops | Repeat Menu Operations |
| Switch Case | Select Banking Options |

## ⚙️ How to Run the Program

### Step 1: Clone the Repository

```bash
git clone YOUR_REPOSITORY_LINK
```

### Step 2: Open the Project Folder

```bash
cd CodeAlpha_Task4
```

### Step 3: Compile the Program

```bash
gcc banking_system.c -o banking_system
```

### Step 4: Run the Program

**For Windows:**

```bash
banking_system.exe
```

**For Linux / macOS:**

```bash
./banking_system
```

## 💡 Banking Operations

**1. Create Account**

Enter customer details to create a new bank account.

**2. Deposit Money**

Add money to an existing account.

**3. Withdraw Money**

Withdraw money if sufficient balance is available.

**4. Balance Enquiry**

View the current account balance.

**5. Exit**

Close the banking application.
